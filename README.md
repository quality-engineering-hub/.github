## Engineering Better Software Through Quality

**Quality Engineering Hub** is an independent, open engineering laboratory dedicated to advancing software quality through practical experimentation, test automation, engineering practices and continuous improvement.

We explore how software can be tested more effectively, defects can be detected earlier, systems can be made more reliable, and engineering teams can deliver software with greater confidence.

This is where theory meets practice.

## Our Engineering Labs

We organise our work into six specialised engineering divisions.

### 01. Web Automation Lab

Building reliable automated tests for modern web applications.

**Focus areas:** Playwright · Cypress · Selenium · UI Automation · Cross-browser Testing

[Explore Web Automation Lab](https://github.com/quality-engineering-hub/web-automation-lab)

### 02. API Automation Lab

Verifying APIs, integrations, contracts and backend behaviour.

**Focus areas:** REST · GraphQL · API Testing · Contract Testing · Integration Testing

[Explore API Automation Lab](https://github.com/quality-engineering-hub/api-automation-lab)

### 03. Mobile Automation Lab

Exploring automated quality engineering across mobile platforms.

**Focus areas:** Appium · Android · iOS · Mobile UI Testing · Device Testing

[Explore Mobile Automation Lab](https://github.com/quality-engineering-hub/mobile-automation-lab)

### 04. Performance Engineering Lab

Understanding application performance, scalability and reliability under load.

**Focus areas:** k6 · JMeter · Load Testing · Stress Testing · Performance Analysis

[Explore CI/CD Quality Engineering Lab](https://github.com/quality-engineering-hub/cicd-quality-engineering-lab)

## Our Engineering Principles

We believe good software quality is engineered, not inspected into existence.

| Principle | What it means |
|---|---|
| Quality First | Consider quality throughout the software lifecycle. |
| Automation with Purpose | Automate meaningful checks, not simply everything. |
| Evidence over Assumptions | Make engineering decisions using verifiable evidence. |
| Continuous Improvement | Learn from failures and improve our practices. |
| Open Knowledge | Share practical knowledge, tools and experiments. |
| Engineering Discipline | Build maintainable, reliable and repeatable solutions. |
